# Sleep function research networks
[Open interactive website](https://lavineyangleo.github.io/sleep-functions-vosviewer/)
Explore one unified keyword network and eight function-specific networks using selection, zoom and keyword search.
Nodes represent WOS DE/ID keywords. Edges count document-level co-occurrence. Colors encode predefined functional assignments, not automatically discovered communities or causal evidence. Function-specific graphs exclude generic sleep terms; the unified graph retains them.
This repository hosts built website assets and aggregate networks, not full-text papers or local reports.
